# Slipfit

CAD for people who print functional parts. You write what a hole is *for* — a bolt
clearance, a nut trap, a press fit — and your printer's own measured behaviour decides the
millimetres at export.

**Documentation:** https://codechomper.github.io/slipfit-releases/
